`@kvant-dev/nordnet` is an ESM-first TypeScript SDK for the web API behind nordnet.se: the same calls Nordnet's own web app makes, not Nordnet's official External API. It owns the HTTP transport and an in-memory session; your application decides how to store the session and present results.

Start with [installation and your first request](/docs/nordnet/getting-started), then read [BankID login and sessions](/docs/nordnet/authentication). Browse the [public API](/docs/nordnet/reference) and its [generated signatures](/docs/nordnet/reference/generated).

## Status

The SDK is new and covers read-only calls: accounts, positions, performance, transactions, orders, watchlists, price alarms, instruments, and market data. There is no CLI for Nordnet yet.

Some response types are not yet verified against a recorded response: the item shapes of positions, transactions, orders, trades, price alarms, and a watchlist's contents. Their types come from nordnet.se's frontend code, so expect them to change as they are confirmed.
